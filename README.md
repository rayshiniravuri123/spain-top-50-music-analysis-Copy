# Spain Top 50 Music Analysis

## Project Overview
This project analyses Spain Top 50 music chart data for Atlantic Recording Corporation to understand song popularity, chart performance, and retention patterns.

## Business Objective
To identify successful songs, understand playlist retention, and generate insights that can support music promotion and playlist planning.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit
- GitHub

## Dataset
The dataset contains:
- Song and artist details
- Chart dates and positions
- Popularity scores
- Song duration
- Album type
- Explicit content information

## Analysis Performed
1. Retention stability analysis
2. Explicit vs clean content comparison
3. Album type-wise retention
4. Duration and album size analysis
5. Popularity growth and decay
6. Business KPI calculation
7. Exploratory data analysis
8. Interactive dashboard

## Dashboard
An interactive Streamlit dashboard was created to explore:
- Key performance indicators
- Top songs
- Popularity patterns
- Album type distribution
- Explicit vs clean content
- Song retention

## Business Recommendations
- Study songs with longer chart presence.
- Monitor popularity trends.
- Compare album type performance.
- Track retention patterns.
- Use insights to support playlist planning.

## Project Outcome
This project demonstrates data cleaning, exploratory data analysis, KPI reporting, visualization, dashboard development, and business insight generation using Python.
